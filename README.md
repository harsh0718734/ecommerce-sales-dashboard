# E-Commerce Sales Performance Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing e-commerce sales performance using Microsoft Power BI. The dashboard provides insights into revenue, sales trends, product categories, and city-level performance through interactive visualizations and key performance indicators (KPIs).

The project analyzes over ₹6.16 million in e-commerce revenue using DAX measures, data modeling, and interactive slicers.

## 🎯 Project Objectives
- Analyze overall e-commerce revenue and sales performance.
- Identify top-performing cities and product categories.
- Track key performance indicators using DAX measures.
- Explore revenue patterns across different business segments.
- Build an interactive dashboard to support data-driven decision-making.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** — Dashboard development
- **DAX** — Measures and KPI calculations
- **Data Modeling** — Structuring analytical data
- **Data Cleaning & Transformation** — Preparing data for analysis
- **Data Visualization** — Charts, KPI cards, and interactive reports

## 📊 Dashboard Features
- Revenue and sales performance analysis
- KPI tracking using DAX measures
- City-wise revenue analysis
- Product category performance analysis
- Interactive slicers for exploring data
- Visual representation of key revenue patterns

## 🔍 Key Analysis Areas
1. Overall e-commerce revenue performance
2. Revenue contribution by city
3. Product category performance
4. Identification of top-performing business segments
5. Interactive exploration of sales data
